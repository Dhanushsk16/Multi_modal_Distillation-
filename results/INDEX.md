# results/

Result folders of the server (`$BTP_DATA/results/`), as written by the scripts. Naming: `harness_<model>*` = the evaluation harness (frozen embeddings, four learners) of a teacher or student; `finetune_<model>*` = fine-tuning runs; `thpep_*` = THPep on the authors' splits; `pool_*` = pool statistics; the rest is named after the script that wrote it. Large prediction files (`preds_*.csv`) are included. The results of the final student also sit in `runs/st6f_results/`.
